# DocuVerify — Frontend Visual

Interfaz de usuario desarrollada con React, Vite y Tailwind CSS para el sistema de validación documental con reglas jurídicas e Inteligencia Artificial.

## Instrucciones de Ejecución

1. Asegúrate de instalar las dependencias: `npm install`
2. Verifica contar con el archivo `.env` basado en `.env.example`
3. Inicia el servidor de desarrollo: `npm run dev`
